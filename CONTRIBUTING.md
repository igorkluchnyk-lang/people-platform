# Як додавати своє

Платформу допрацьовуємо разом. Правило одне: у репозиторії тільки код і вигадані приклади, без реальних людей, сум, переписок і ключів.

## Ідея або баг

Відкрий Issue: що хочеш, навіщо, як зрозуміти, що зроблено. Скрін або 2-3 речення достатньо.

## Своя зміна

1. Fork або гілка `feature/<коротко>`.
2. Зміни `platform.html` (або скрипт). Новий блок пиши поруч зі схожим і познач коментарем `/* vNN: що це */`.
3. Нова колекція в базі: додай рядок у «Схема бази» в README і приклад у `seed_example/<колекція>/`.
4. Налаштування команди (імена, канали, цифри) не хардкодь: тільки через `CFG`, `ORDER` або поля в базі.
5. Перевір перед PR:
   - `node --check` на скрипті сторінки (витягни вміст `<script>` у файл);
   - сторінка відкривається на `seed_example` без помилок у консолі: дашборд, «Цілі», людина, «Тижневий синк», «Місячний синк»;
   - пошук по імені своєї компанії, людей, email і Slack ID дає нуль збігів.
6. Pull Request: що змінилось, скрін, як перевірити. Онови «Версії» в README.

## З Claude Code

Скажи сесії: «Прочитай CONTRIBUTING.md у people-platform, додай <що> і відкрий PR». Вона зробить гілку, перевірки з пункту 5 і PR.

## Зі своєї робочої копії назад у шаблон

Якщо ти вже розгорнув платформу у своїй команді і зробив корисну фічу: перенеси тільки код (без даних) у fork шаблону і відкрий PR. Попроси Claude прибрати імена, канали й цифри та винести їх у `CFG`.
